- 2026-08-18 — **Naming research for E1 (hub consumer name) — findings recorded, name still OPEN.** Three waves, 20 names collision-checked, 50+ domain lookups. (1) **The 4–5 character domain space is exhausted on `.com` AND `.ca` alike** — 0 of 8 free using pronounceable *nonsense* strings, because any 4–5 letter string is a real word in some language. Real words are claimed at ANY length (`fidus`, `custos`, `fidelis`, `fiducia`, `custodia` all taken on `.ca`). `.ca` only diverges from `.com` at 6+ chars, where it is much freer (CIRA's Canadian Presence Requirement excludes global squatters). **Consequence: "1–2 syllables + exact registrable domain" is impossible. Pick two of {short, exact-match domain, available today}.** (2) **Dead — do not re-check:** Keel (UK BaaS, exited stealth 05/2026), Reckon (ASX-listed accounting, RKN), Trove (Nigerian investing app), Tally, Fathom (fathomhq financial reporting), Kestrel (agri neobank + Kestrl Islamic fintech), Alder (Alder Financial ×2, Aldermore), Lintel (UK banking), Croft (Croft Finance OS), Sheaf (sheaf.ca — tracks subscriptions/licences/renewals, uncannily close to us), Tenon (Tenon Financial aggregates accounts "into one view"), Quoin (Quoin Ventures portfolio app + Qoins), Tarn (usetarn.com = crypto portfolio tracker), Larder (three live food companies), Vellum (vellum.ai owns the search results). **Only survivor of 20 on class-36 headroom: Marlow** — owner didn't connect with it. (3) **Method note that matters more than any name:** sweeping `get`/`use`/`try`/`hq` + name for RECENT registrations is a better stealth-company detector than web search — it caught Keel, Tarn and Larder, which search missed or under-reported, because small shipped products generate no press. Run the domain-variant sweep BEFORE the search. (4) **Tooling traps, cost me two wrong answers:** plain `whois` is unreliable for new gTLDs (falls through to IANA and returns a TLD description that reads as a hit — this is why `marlow.money` was first reported taken when it is free); `rdap.org` returning 404 is ambiguous, meaning EITHER available OR no-RDAP-server-for-this-TLD (it wrongly cleared `marlow.io`, registered since 2018). Use the authoritative per-TLD RDAP from `https://data.iana.org/rdap/dns.json` and always run a control (known-registered → 200, gibberish → 404) before trusting a batch. `.ca` = `https://rdap.ca.fury.ca/rdap/`, `.com` = `https://rdap.verisign.com/com/v1/`, Identity Digital (`.money`/`.finance`/`.cash`) = `https://rdap.identitydigital.services/rdap/`. (5) **Free as of today** (all control-verified): `muwwakil.com` + `muwwakil.ca` — the ONLY exact-match `.com` found in the whole search, available because it is 8 chars with a doubled-w; `marlow.money`/`.finance`/`.cash`; and on `.ca`: `wakala`, `wakalat`, `mandata`, `credere`, `servata`, `thiqa`/`thiqah`/`thika`, `amanya`, `amanata`. - 2026-08-17 — Statement matching runs an ordered pass table (exact → tip-tolerant → pre-auth hold), each pass sweeping the whole upload before the next starts. The pre-auth pass claims lines where the candidate is ABOVE the statement — a pump or hotel hold that settled lower — and drops the amount test entirely, so merchant identity carries the whole proof (similarity ≥ 0.9, unique in window, or ambiguous). As the amount test weakens down the table the other gates tighten. Holds are proposals like tolerant matches: excluded from coverage, never flipping a wallet event, settled by the user via resolveProposedMatch. Not covered: the $1.00 verification probe, whose capture bears no relation to the settled amount.
- 2026-08-17 — Statement reconciliation filters candidates to the card's billing currency (storage default CAD, matching walletNormalization/purchaseMerge). Foreign purchases are now honestly unmatched; converting via the FX engine instead would need its own narrow FX-drift band, since issuer rate + FX fee drift lands inside the 25% tip band.
